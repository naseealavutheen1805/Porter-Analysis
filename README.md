# Porter Order & Delivery Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing delivery performance for Porter using Excel. The dataset was cleaned, explored using pivot tables, and visualized in a dashboard to understand order volume, delivery speed, market behavior, and customer ordering patterns.

## 📊 Key Metrics
- **Total Orders:** 169,849  
- **Top Store Category:** American  
- **Deliveries < 30 Minutes:** 32.17%  
- **Peak Ordered Time:** 2 AM  

## 🛠️ What Was Done
- Cleaned and prepared the delivery dataset  
- Answered project questions through pivot table analysis  
- Explored orders by market, hours, store category, and protocol  
- Built an interactive Excel dashboard with slicers for Market, Day, Category, Protocol, and Time Status  

## 🔍 Dashboard Insights
- Market **2** has the highest order volume (52K+ orders)  
- Order activity peaks at **2 AM** and drops throughout the day  
- American stores receive the highest number of orders  
- Japanese and Italian categories show higher average order values  
- Protocol **2** and **3** handle most order traffic  
- Subtotal vs Total Items shows wide variation in order size
